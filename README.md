# University Python Calculator

A simple modular calculator written in Python.

## Features

The calculator supports:

* Addition
* Subtraction
* Multiplication
* Division
* Power
* Division-by-zero handling
* Input validation

## How it works

The calculator uses a `Calculator` class with separate methods for each mathematical operation.

The program asks the user to enter:

1. The first number
2. An operation (`+`, `-`, `*`, `/`, `^`)
3. The second number

It then calculates and displays the result.

## Example

```text
--- Модульный калькулятор на Python ---
Введите первое число: 10
Введите операцию (+, -, *, /, ^): *
Введите второе число: 5
Результат: 50.0
```

## Error handling

The program handles:

* Invalid number input
* Division by zero
* Invalid operators

## Technologies

* Python 3
* `math` module
* Classes and methods
* Exception handling
